This is the first stable release in the 2.54 series.

### Highlights of the WPE WebKit 2.54.0 release

- The [WPEPlatform](https://wpewebkit.org/reference/2.54.0/wpe-platform-2.0/)
  embedding API is now considered stable and enabled by default at build
  configuration time. The legacy `libwpe`-based API is still available, and
  may be deprecated in the future.
- Add new API for page favicons, using
  [WebKitFaviconDatabase](https://wpewebkit.org/reference/2.54.0/wpe-webkit-2.0//class.FaviconDatabase.html)
  and the [WebKitWebView:page-icons](https://wpewebkit.org/reference/2.54.0/wpe-webkit-2.0//property.WebView.page-icons.html)
  property.
- Add the [WebKitWebView:magnification](https://wpewebkit.org/reference/2.54.0/wpe-webkit-2.0/property.WebView.magnification.html)
  property, to handle visual scaling.
- Add new API to allow setting a per-navigation custom `User-Agent` to
  [WebKitWebsitePolicies](https://wpewebkit.org/reference/2.54.0/wpe-webkit-2.0/class.WebsitePolicies.html).
- Add support for gamepad rumble effects.
- Add support for spell checking using the [Enchant](https://rrthomas.github.io/enchant/)
  library.
- Add initial support for the [Pointer
  Lock](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API) API.
- Switch Web Process compositor to use Skia instead of TextureMapper.
- Improved WebXR implementation, which now includes support for the
  [Layers API](https://www.w3.org/TR/webxrlayers-1/).
- Improved damage handling that is now also used during the composition to
  limit the composited areas.
- Implement GPU atlas creation and replay substitution for batched raster
  image uploads.
- Media capability reporting is more accurate.
- Video decoding limits are now respected in media capabilities queries.
- Remove the option to use Cairo for 2D rendering.

For more details about all the changes included in WPE WebKit 2.54 see the
`NEWS` file that is included in the tarball.
